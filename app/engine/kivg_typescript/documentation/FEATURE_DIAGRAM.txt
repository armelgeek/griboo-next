KEY COMPONENTS
══════════════

┌────────────────────────────────────────────────────────────────┐
│ SceneCanvas (scene-canvas.ts)                                  │
│  ├─ Double-click event handler on stage                        │
│  ├─ Position calculation (screen → scene coordinates)          │
│  ├─ Layer creation and management                              │
│  └─ openTextEditor() method                                    │
└────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌────────────────────────────────────────────────────────────────┐
│ TextLayer (layer-text.ts)                                      │
│  ├─ Konva.Text node                                            │
│  ├─ Double-click event listener                                │
│  ├─ onDoubleClick callback → opens editor                      │
│  └─ update() method to change text                             │
└────────────────────────────────────────────────────────────────┘
                              │
                              ▼
┌────────────────────────────────────────────────────────────────┐
│ TextEditor (text-editor.ts)                                    │
│  ├─ Modal overlay                                              │
│  ├─ Textarea for text input                                    │
│  ├─ Save/Cancel buttons                                        │
│  ├─ Keyboard shortcuts (Ctrl+Enter, Escape)                    │
│  └─ Callbacks for save/cancel actions                          │
└────────────────────────────────────────────────────────────────┘


KEYBOARD SHORTCUTS
═══════════════════

  Ctrl+Enter (or Cmd+Enter)  →  Save and close editor
  Escape                     →  Cancel and close editor
  Click outside modal        →  Cancel and close editor
