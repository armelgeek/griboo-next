🎯 Test: Sélection Multiple par Glissement

Testez la fonctionnalité de sélection multiple d'éléments

Instructions:

  • Glissez sur la scène pour créer une zone de sélection (rectangle bleu)
  • Tous les éléments dans la zone seront sélectionnés
  • Ctrl+Click pour ajouter/enlever des éléments de la sélection
  • Delete ou Backspace pour supprimer les éléments sélectionnés
  • Escape pour tout désélectionner
  • Maintenez Espace pour déplacer la scène
Sélection: Aucun élément sélectionné
