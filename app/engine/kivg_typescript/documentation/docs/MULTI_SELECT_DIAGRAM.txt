INTERSECTION DETECTION (AABB)
══════════════════════════════

Selection Box:          Layer Node:
  (x1, y1)                 (nx1, ny1)
     ┌─────────┐              ┌─────┐
     │         │              │     │
     │         │              │     │
     └─────────┘              └─────┘
            (x2, y2)               (nx2, ny2)

Intersection Test:
  NOT (nx2 < x1  OR  nx1 > x2  OR  ny2 < y1  OR  ny1 > y2)

If TRUE → Layer is selected
If FALSE → Layer is not selected

KEYBOARD SHORTCUTS
══════════════════

  Ctrl+Click      →  Add/Remove element from selection
  Cmd+Click       →  Add/Remove element from selection (Mac)
  Delete          →  Delete all selected elements
  Backspace       →  Delete all selected elements
  Escape          →  Deselect all elements
  Space+Drag      →  Pan mode (no selection)


COORDINATE TRANSFORMATIONS
═══════════════════════════

Screen Coordinates → Scene Coordinates:

  sceneX = (screenX - layerPosX) / zoom
  sceneY = (screenY - layerPosY) / zoom

Why needed?
  • Canvas can be panned (layerPos)
  • Canvas can be zoomed (scale)
  • Selection box is in screen space
  • Layer bounds are in scene space
  • Must convert to same coordinate system for comparison


STATE MANAGEMENT
════════════════

Single Selection (Legacy):
  selectedLayerId: string | null

Multi Selection (New):
  selectedLayerIds: Set<string>

Backward Compatibility:
  • selectedLayerId is set to first selected element
  • Existing code continues to work
  • New code can use getSelectedLayerIds()


PERFORMANCE CONSIDERATIONS
═══════════════════════════

✓ Set<string> for O(1) lookup/add/remove
✓ AABB for fast intersection detection
✓ Only check layers during drag end (not every frame)
✓ Batch draw updates (batchDraw())
✓ Minimal DOM manipulation
