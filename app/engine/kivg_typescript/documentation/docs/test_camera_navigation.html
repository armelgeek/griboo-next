📖 Comment utiliser la navigation rapide

  • Ctrl+1 à Ctrl+9 - Aller directement à la caméra 1-9
  • Ctrl+→ ou Ctrl+↓ - Caméra suivante
  • Ctrl+← ou Ctrl+↑ - Caméra précédente
  • Ctrl+Tab - Caméra suivante (avec Shift pour précédente)
  • Cliquez sur le widget en haut à droite pour voir toutes les caméras
